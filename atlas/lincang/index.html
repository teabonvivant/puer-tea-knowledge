在臨滄這個大範圍裏繼續細讀

臨滄的茶區跨越河谷與山地。地形、茶樹材料、採摘和加工各有差異，用一個市名很難概括杯中的香氣與滋味。把地理範圍逐步縮小，才較容易連上地方調查與具體茶樣。

冰島可沿雙江、勐庫的行政關係理解；昔歸要放回臨翔、邦東的地理位置；白鶯山則連到雲縣、漫灣。熟悉這些層級之後，商品說的是整個村域、某一寨子還是一片茶園，便有了可以追問的基礎。

重要地理脈絡

  • 雙江縣 → 勐庫鎮 → 冰島村：每一層代表不同範圍，商品聲稱須指出實際採摘單元。
  • 臨翔區 → 邦東鄉 → 昔歸：村名、茶區名及市場用法需互相核對。
  • 雲縣 → 漫灣鎮 → 白鶯山：古茶資源資料不可泛化為全縣屬性。
  • 鳳慶縣：同時是大葉種資源、製茶及滇紅歷史的重要研究區；產地不等於茶類。
  • 永德縣：需要縣、鄉、村及樣本資料，不能由市級統計代替。

勐庫大葉種是名稱也是研究問題

地方群體、審定品種、種質材料及商品原料的身份層級不同。研究或銷售若使用『勐庫大葉種』，應交代鑑定方法、來源地、繁殖方式與樣本數；不能只憑葉片大或產於勐庫便完成品種判定。

古茶樹資料的最低要求

  • 植株或群落位置與保護身份。
  • 調查機構、日期、量測方法與不確定度。
  • 植株、地塊和加工批次之間的連結。
  • 採摘是否獲准及有否遵守古茶樹保護要求。

建立可比較資料

跨臨滄子產區比較時，要在同一年與季節收集多個獨立地塊，記錄相同加工方案，並保留產區內變異。若樣本來自市場，結論應寫成『標示為某地的商品樣』，不升格為產地定律。

閱讀提示： 本庫收錄地理關係與來源，不替未有追溯鏈的商品背書。
